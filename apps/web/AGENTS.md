# apps/web — aturan agent

Aturan web sama dengan yang dipakai Claude Code. Tidak ada salinan: file ini cuma pointer ke sumber aslinya.
File ini + rules di bawah dimuat on-demand - hanya saat task menyentuh `apps/web`.

Sebelum mengerjakan task yang menyentuh `apps/web`, baca berurutan:

1. `../../CLAUDE.md` (root) - tiga pilar wajib + aturan bersama
2. `CLAUDE.md` (app ini) - rujukan arsitektur & produk
3. `.claude/rules/security.md`
4. `.claude/rules/performance.md`
5. `.claude/rules/code-quality.md`

Arsitektur app: `ARCHITECTURE.md`. Produk: `docs/PRD.md`. Baca saat relevan, jangan di-import.
