Pill-shaped action button; primary accent fill is the main CTA, outline/dashed/ghost for secondary actions.

```jsx
<Button>Simpan ke jurnal</Button>
<Button variant="outline">Hari ini</Button>
<Button variant="dashed" block>+ Tambah jadwal</Button>
<Button size="lg" chunky>Mulai fokus</Button>
```

Always pill radius. Disabled = 45% opacity (memo save with empty text).
