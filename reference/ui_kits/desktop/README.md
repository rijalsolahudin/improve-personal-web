# Improve Personal — Desktop

Sidebar app shell (collapsible), Home dashboard with rearrangeable widget grid, Kalender, To-do, Eisenhower, Pomodoro, Goals, Habit, Jurnal, Countdown, Overview. Three themes, sticker decorations.

Source of truth: `/Home Desktop.dc.html` (fully interactive Design Component). This kit embeds it directly instead of re-implementing it, so it never drifts.
