## Tiga pilar

- **Keamanan:** tidak ada `v-html`/`innerHTML`/`eval` baru di delta (`git diff | grep`), tidak ada secret; kategori goal disimpan sebagai record `goal_category` (bukan localStorage) - satu-satunya `localStorage` di delta hanya kunci deko yang sudah ada sebelumnya. Input label kategori divalidasi di core (`strict()`, trim, maks 40, anti-duplikat, pagar 50 kategori).
- **Performa:** tidak ada dependency baru (tidak ada perubahan `package.json`); animasi hanya `opacity`/`transform`/`translate`/`box-shadow`; tidak ada fetch baru di loop. Bonus: label slot grid dihitung sekali per hari (`CalendarTimeGrid.vue:85-101`) alih-alih 672 `Intl.DateTimeFormat` per render.
- **Kerapian:** gate developer sudah hijau (prettier+eslint+typecheck). QA cek manual: tidak ada `any`/`@ts-ignore`/`console.log` di delta, ekspor mati (`dailyPriorities`, `PRIORITY_VISIBLE_COUNT`, `GOAL_CATEGORY_GLYPH`, `goal.links.*`) sudah ikut dihapus, tidak ada `.only`/`.skip`.

## Sisa risiko / tidak diuji

- Belum diverifikasi visual di browser (dev server tidak dijalankan): kehalusan modal/sheet/checkbox/sticker press, ring fokus dashed, auto-scroll grid ke jam sekarang, dan tampilan drag preview. Semua dibuktikan lewat kode + test, bukan mata.
- "Warna otomatis = warna belum terpakai" lewat modal belum ada test UI; aturannya sudah diuji di core (`nextGoalCategoryColor`, `goal-category.test.ts`).
- E2E/PWA, Lighthouse, dan suite penuh tidak dijalankan (T3, wewenang orchestrator).
